# 细分品类网站优化提示词

将占位信息替换为真实资料。主提示词独立可执行；品类与阶段附加段按需追加。词组是研究种子，不是已验证的趋势。使用 [季节规划助手](../scripts/seasonal_plan.py) 可把明确日期/交期填入逐品类提示词。

## A. 通用主提示词（跨行业）

```text
使用 $renwork-site-audit-optimizer，对【网址/源码】的【细分品类】进行研究驱动的网站优化。
目标买家：【品牌采购/进口商/分销商/工程商等】；国家/语言：【】；研究日期和计划年度：【】。
已有页面：【URL/模板】；真实企业/产品/检测/报价资料：【文件】；未知事实不要补造。
消费者或项目使用窗口：【已知日期或待核实】；买家目标到货/上架日：【】。
采购评审、打样确认、生产、验货、运输、清关、上架缓冲：【各环节 min/max 日历天及来源；无资料写未知】。

请连续完成：
1. 查看当前网站及源码，拆出“产品×用途×属性×买家×市场”研究单元，区分消费者词、B2B采购词和买家问题，识别同义页冲突。
2. 采集 Google Trends 多年季节形状和近期变化，保留地区/时间/类型/Topic或词语/采集时间/原始导出；查 Pinterest 适用市场的搜索、收藏、购物、季节活动与预测；查可用 AI 平台本站报表，用固定买家问题组观察答案与引用。与匿名历史询盘/订单时间交叉判断。
3. 不同来源分别记录。指数不是订单量，AI问题组不是全网搜索量，预测不是实测；登录/低样本/缺失数据写明。各结论标记证据、推断或假设，不编“实时趋势”。
4. 按实际年份、地区、气候/半球、节日/赛事/项目和工厂假期，倒推采购启动、样品、生产、交货和内容准备日期。给出保守/较紧情景与当前阶段；交期未知时只生成待填方案，继续有证据的常青优化，不造精确日历。
5. 针对阶段修改：首页模块、品类导航、Title/H1/描述、规格与材料比较、可公开测试证据、图片方向、采购FAQ、内链、样品/RFQ入口和预填上下文。说明改哪页、为何现在改、所需事实及衡量指标。
6. 有源码时直接实施已授权修改并验证。Schema只反映可见真实事实；保留品牌、公司/邮箱、有效URL和有意索引策略。未知价格、MOQ、认证、产能、关税、交期保持缺口，不批量造薄节日/地区页。
7. 交付逐品类趋势证据、采购日历、页面行动矩阵、改后项目、完整diff、变更说明和复测；区分已实施/已验证/未完成。不要把旺季自然上涨当改站成果，提供下一轮复核条件；未要求持续监测时不自行设置定时任务。
```

## B. 五类服装附加段

### Activewear / Fitness & Seamless

```text
聚焦 squat proof leggings、seamless gym set、compression shirts，补充目标语 OEM/private-label 表达。
验证常青训练需求与新年健身/零售活动的增量差异；消费者热度和品牌打样时间分列。
回答：湿/干与拉伸条件下遮蔽、起球/耐磨、腰头稳定、缝合摩擦、材质克重及尺码如何选。
依据真实规格/报告优化材料比较、定制项和样品资料清单，不自动填75/25成分、220 GSM或“100% squat-proof”。
```

### Sportswear / Heavyweight & Athleisure

```text
以 heavyweight hoodie、400 gsm hoodie、french terry blanks 为研究种子，核实目的地气候、街头服饰系列与买家渠道。
用真实 GSM/成分/手感、缩水测试条件、洗水、版型和辅料组织规格模块；“400 gsm”是查询意图，不能替代实际参数。
为样品评估与批量排产设置不同CTA。无证据不写有机认证、缩水率、指定辅料品牌或固定FOB。
```

### Running Wear / Marathon & Trail

```text
研究 running singlet、marathon racing vest、split shorts；赛事日期取当年主办方资料，区分赛事采购、团队和零售品牌。
从团队到货/发包时间倒排样品、尺码确认、定制、生产和交运，不把比赛日作为采购峰值。
优化重量测量条件、摩擦点、排汗/反光实测及尺码分配模块；询盘预填品类并让用户确认期望到货日，不自动承诺65 GSM或20天交期。
```

### Swimming Wear / Performance & Resort

```text
分别研究泳池训练、竞技泳装、度假泳装；种子包括 chlorine resistant swimsuit、recycled swimwear fabric、ribbed bikini wholesale。
目标市场北/南半球、全年泳池与度假季分开，按买家上架日和实际交期计算采购窗口，不固定“10月至2月”。
区分氯水/海水、湿态遮蔽、衬里/弹性保持与材料证据，逐型号核对报告及回收认证范围；不代填具体混纺、认证等级或“安全无害”。
```

### Beach Wear / Sun & Surf

```text
研究 rashguard、sun hoodie、stretch boardshorts 对应的防晒/冲浪/旅游买家；Pinterest用于场景、配色与款式假设，不能替代性能测试。
按目的地气候、活动和到货计划决定CTA是开发样品、排产确认还是补货可行性咨询。
UPF/干燥/伸展/接缝声明绑定适用产品、条件和有效报告；不扩展为医学防癌承诺，不照抄固定阻隔率或25分钟干燥。
```

## C. 阶段复用段

```text
旺季前：解决选型、打样和采购资料缺口；明确所需规格/数量/市场/期望到货日。公开交期只写经确认条件，规划日期不是承诺。
紧窗口/已过窗口：依据真实库存、产能和物流评估补货，不加“加急保证”或虚假倒计时；不可行则引导替代规格或下一季开发。
淡季/季末：保留有价值的产品URL，撤下过期活动/承诺，补材料比较、检测和案例，开始下一季样品研究；不编促销折扣或清仓库存。
```

## D. 单次滚动复核

```text
对【品类/市场】做一次趋势与采购窗口复核，沿用上次证据、日历、问题组及页面版本。
核对数据新鲜度、指标口径、实际询盘和供应变化；分开报告新增信号、噪声、缺口及要改的页面。
用同口径同比/活动相对周期比较，标出窗口/引擎变化，不把自然季节性当优化收益。
有依据且在既有授权内就完成修改和复测，否则保留页面并记录下次复核条件。
这是一次运行，不自行设置周期任务或自动发布。
```
