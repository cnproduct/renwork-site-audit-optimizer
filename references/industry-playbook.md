# 按采购场景优化既有网站

行业决定信息与交互，不能只换配色。沿用真实企业资料；下表列的是要核实/补齐的需求，不是允许自动生成的公司能力。

需要进一步细分品类或根据采购季调整页面时，转到 [细分品类与趋势方法](category-seasonal-growth.md)。原有行业字段作为底表，再增加场景、属性、买家、市场与时间窗口；不重建一套不兼容的企业事实库。

| 行业族 | 详情/选型重点 | 有效询盘应带的上下文 |
|---|---|---|
| 工业设备、机械、自动化 | 工况、产能条件、能耗/接口、安装/维护、配件与真实工程资料 | 工况/产线、目标处理量、场地/电源、目的地 |
| 电子元件、电气、新能源 | 型号、封装、兼容/额定参数、测试条件、datasheet 版本、追溯与合规范围 | 型号/替代需求、数量、关键规格、项目阶段 |
| 卫浴、五金、建材、石材 | 尺寸/材质/表面、安装体系、应用环境、颜色与批次差异、包装/样品 | 规格/饰面、应用/图纸、数量、目标市场 |
| 卫生用品、医疗耗材 | 结构/材料、尺寸/适用人群、包装、测试方法、认证适用主体/产品 | 产品类型、规格、私标包装、目的市场；避免收集患者信息 |
| 包装、印刷、塑料/金属加工 | 材质/公差/工艺、文件要求、打样流程、模具归属、可回收声明证据 | 图纸/尺寸、材料、印刷/表面、数量与应用 |
| 纺织、服装、鞋履、家居 | 面料/成分、尺寸表、色号、工艺、样品与尺码/颜色组合 | 款式、材质、尺码组合、数量、OEM 需求 |
| 食品、农业、化工原料 | 等级/成分、批次检验、保质/储存条件、运输限制、SDS/检测资料 | 品级/用途、规格、数量、运输地；未知法规不代填 |
| 消费品、礼品、家具 | 尺寸/选项、包装、使用/组装、品牌定制、零售渠道适配 | 型号/变体、标识、包装、数量与渠道 |
| 软件、专业服务、综合贸易 | 交付范围、适用限制、集成/服务流程、真实案例与职责边界 | 业务问题、已有系统、使用规模、所需服务范围 |

跨行业共用的页面顺序可以是“需求/用途 → 适配条件 → 产品/服务 → 证据 → 下一步”，按实际采购复杂度调整。对工程采购突出参数和下载；对设计/饰面采购突出实物细节与样品；对 OEM 采购突出配置流程与质量控制。无需把所有行业模块塞进每个站。

高颜值的验收应落到可见改善：例如同一产品信息从不可读长段落改成有单位的规格表、移动询盘入口不再被悬浮按钮遮挡、不同语言的长标题不截断。询盘字段先满足销售判断所需的最小信息，可选字段逐步展开，不制造无依据的强制 MOQ/预算门槛。
