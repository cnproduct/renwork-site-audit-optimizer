# 直接优化手册

## 实施位置与回退

读取项目 AGENTS、构建命令、模板与路由后修改。保留现有框架、CMS 数据结构、有效 URL、DNS/邮箱配置和用户工作区改动；用户已授权的正常可逆修复持续执行。Git 项目在当前任务允许的分支/独立 worktree 修改，共享修复落在共同组件。CMS 先保存原字段/模板版本再编辑，不在无法回退时批量替换。

只有线上 URL 时不把下载来的 HTML 当源码部署：浏览器检查、定位模板问题、交付可复制的替换稿或精确修改位置；获取写入入口之前状态为 PROPOSED。原站是 Next/Nuxt/React 等时先追到组件/数据源，不能只修改 dist。静态站可用脚本产生候选副本，再结合浏览器完成其余优化。

## 常见问题 → 直接修改 → 复测

| 问题 | 实际修改 | 必须保留的证据 |
|---|---|---|
| 首屏不清楚、询盘入口埋藏 | 用已证实的产品/服务/市场信息重写主标题和辅助文案，强化单一主要行动，给次行动较低视觉权重 | 同内容、同断点前后截图；CTA 实际目标与键盘路径 |
| 模板感、字体杂乱、移动溢出 | 从既有 Logo/品牌规范提取有限颜色与字体角色，统一间距/组件；修复真实布局原因，不用全局 overflow:hidden 掩盖 | 320/390/768/1440px 代表样本；200% 原生缩放，焦点可见 |
| 产品详情空泛 | 将获准规格、应用条件、兼容性、选型/定制流程重组为可扫描内容，保留单位/限制/来源 | 逐事实来源、可见正文与 Schema 一致性；无证据字段入缺口列表 |
| 标题/描述泛化 | 按页面实际采购意图重写，不硬套字数、虚假“领先/最低价/认证” | 修改前后正文与元数据；避免全站同标题 |
| canonical/索引错误 | 确认生产/预览意图后修正源配置，处理真实重复与旧 URL 重定向 | 原始响应头+HTML+重定向、sitemap；不擅自移除有意设置的 noindex |
| 有 Schema 但不可信 | 删除或修正无事实支持字段，选适用类型，把数据绑定可见内容的同一真实来源 | 语法/语义检查和页面截取；富结果工具只是资格测试的一部分 |
| 图像拖慢、布局跳动 | 保存原件，生成适合尺寸和格式的变体，写尺寸/aspect-ratio；仅非首屏图按需 lazy；保留实际 LCP 图优先级 | 文件大小/尺寸、网络瀑布、同条件 LCP/CLS；不承诺即时改善 CrUX 窗口 |
| JS 负担过重 | 删除确实无用的依赖/重复逻辑，延迟非关键第三方脚本；先查项目现成能力 | 构建和关键交互、主线程/请求记录；不能破坏同意管理或分析口径 |
| 表单“成功”但无结果 | 修复服务端校验、端点、错误状态、pending、防重复及真实结果判断；日志与通知用关联 ID | 本地成功/失败/超时/重试；获准生产测试的收件/CRM ID；不记录敏感正文到公开报告 |
| 内容缺乏 AI 可引用性 | 把实际采购问题和条件写清楚，添加必要表格、定义、真实引用与更新时间 | 可见可索引正文、来源；AI 实测记录模型/日期/市场/问题/引用 URL，不能按一次回答推全网 |
| 多语言模板残留 | 修正错语言、单位、公司身份，已存在语言页做正确互链；RTL 按实际布局测试 | 逐语言截图、切换目标、hreflang 与 canonical；不复制大量空语言页 |

视觉优化与安全/性能冲突时先保住可用性、可访问性和询盘路径。新增营销承诺或企业事实必须有证据；新增付费服务、外部追踪、生产消息、域名/DNS 变更不由“优化网站”自动扩展授权。

## 复测与上线

运行项目现有构建及与改动相关的测试；浏览器查看实际页面，验证菜单、规格表、下载、语言切换及所有变更的 CTA。表单既测正常也测失败和重试；没有真实收件就保留 delivery 未完成。选同页同设备做 before/after，对动效允许 reduced-motion。

部署后检查真实域名的关键 URL、响应头、robots、sitemap、资源和询盘链路；本地成功不能复制为线上成功。用户未授权部署时交付可审阅的候选和回退方式，不提前宣称上线。搜索平台权限不足仍完成公开可检工作，不伪造账号数据；收录、AI 引用和业务指标按实际观察期追加，若需要后续定时任务另依用户要求设置。
